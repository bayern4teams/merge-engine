## What changed
- `destination_schema_defects(state, schemas) -> list[dict]` - PURE, module-level. `schemas` =
  `{table: get_table_schema(table)}` for every destination table (keys double as the available-table
  list; only `columns[].name` is read). Returns JSON-safe dicts (empty list = healthy):
  `{"entity","table","missing_columns":[sorted],"unprojectable_rows":int,"held_links":[{"id","values":{col:value}}]}`.
- `read_destination_schemas(connector) -> dict` - the I/O half (list_tables + get_table_schema; `{}` and a
  warning if the connector cannot introspect). Gate use:
  `destination_schema_defects(state, read_destination_schemas(connector))` from `_build_..._interrupt(state)`.
- `_resolve_dest_table(destination, entity, available)` - the entity->table resolution that was copy-pasted twice in
  `_load_all_entities`; both copies now call it (behaviour identical), and the new function reuses it.
- Node: computes defects after the connector opens (before the transaction), skips defective entities in
  `_load_all_entities` (new `skip_entities` param) so 0 rows / no load_batch for that table, appends one error line per
  defect, adds `report["destination_defects"]` + a red flag (grade already C via zero-row family), and returns
  `update["destination_defects"]`. Keys are ABSENT when there is no defect (a healthy run is unchanged).
  Persisted run report gets it (written after). Dry run reports it too. No DDL path added; `_apply_schema_changes`
  still only refuses.

## Detection rule (no name tests, no constants)
needed = `dest_column` of mapping entries aimed at the table (dest_table or own) + `unmapped_fields[entity]` field names;
missing = needed - declared columns. Defective iff missing is non-empty AND every declared column other than `id` and
`_`-prefixed provenance is one of the needed ones (the table exists only to hold these links and cannot). Unprojectable
rows = unified records with a non-blank value for any missing column (source field read via the mapping).
A table that does not exist yet (no columns) is skipped (ensure_table's job).
