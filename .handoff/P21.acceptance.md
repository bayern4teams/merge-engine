Source: `TECHNICAL_REPORT_2026-09-26.md` P21 §Acceptance (items 1–9), rev. b
additions (10–11), rev. c additions (12–20), plus `docs/er_contract_v13.md`.
Written 2026-11-24 **before** the P21a–k implementation; items below freeze what
"done" means. Tests land under `tests/part1/` as `test_p21_acceptance.py`
(mocked/unit tier) and `test_p21_live.py` (live tier).

Live tier is env-gated: `MERGE_ENGINE_LIVE_DB=1` (else every live test skips —
CI has no Postgres/Mongo). Connection facts come ONLY from the gitignored
`.env` (`ER_TEST_PG_PASSWORD`, `ER_TEST_PG_HOST`, `ER_TEST_PG_PORT`,
`ER_TEST_MONGO_URI`) — no credential, host or port literal in any test file or
commit. Each live session creates its own schema `p21_itest_<runid>` on the
test database and drops it after; `public` is never touched. Mongo tests run
against a throwaway local mongod via `ER_TEST_MONGO_URI`.

Run live tier:
`MERGE_ENGINE_LIVE_DB=1 .venv/bin/python -m pytest tests/part1/test_p21_live.py -q -p no:cacheprovider`

Every side table gets an ensure_* idempotency check (run twice, identical
catalog, no error). Item 9 (recall@5) and item 8 (p95) are **reported, never
asserted** — no quality assertion tonight (owner rule).
