## Judgement calls for the lead
- **J1 "strictly one-to-one required".** No destination constraint is readable, so the contract is an explicit `one_to_one=True` from the caller, default off.
  Waive with `P20_ONE_TO_ONE=skip` and record why; a silent skip is not allowed.
- **J2** a data-derived design should not depend on the absolute `_MIN_COHESION = 0.90`; if the lead keeps it as a safety net, drop the `test_j_*` pair.
- **WNP is lossy by design.** A true edge below the local mean at BOTH ends is pruned, so a chain with jittered weights or doubly-bridged true edges can
  fragment. The planted worlds therefore give one weight per entity and keep wrong edges off both ends of a true edge. That is the report's recall trade, not tested as a defect.
- **Raw Phase 0 fixtures** carry no name signal ("a0".."b4"), so `sparse_true_cluster_chain` (whole) and `chain_via_singleton` (x apart) are only both satisfiable
  from structure (the oracle uses triangle support). A pure name-based design must stay neutral on uninformative names.
- **Aliases with no lexical overlap** (IBM / International Business Machines) are out of scope: heuristic ceiling, untested.
- `name_variation_rate` argument shape (a list of names) is mine; a different shape is one change in `_variation`.
