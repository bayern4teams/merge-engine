## New defects (strict xfails under "# r2" in tests/part1/test_p16_attack.py; controls pass)
- D1 MEDIUM, one junk name masks a fused cluster. Containment is `joined.find(name)` with no length floor, so a 1-char record name ("e", "s", "a") is "contained"
  in every name holding that letter and unions the groups: ["Vodafone","Tesco","Shell"] flagged, + "e" not flagged; ["Acme Widgets","Zyxwv Holdings"] + "s" not flagged.
  A bridging real name ("Shell BP Joint Venture") does the same. Fix idea with no new constant: count a containment only when the contained name is >= half of the
  container (the same rule the token link uses), or ignore names that are a single character.
- D2 MEDIUM-LOW, a pure reorder is flagged. "Patricia Williams" / "Williams, Patricia": each token is 8 of 17 chars, 16 < 17, so neither the token rule nor containment links
  them. 5-7% of generated 2-4 name person clusters flagged (e.g. 'Karen Moore','Moore, Karen'; 'Linda Jones' + 'Jones, Linda'); a middle initial adds more. Equal token SETS
  should link.
- D3 LOW-MED, "near-linear" is quadratic past ~10k distinct names in one cluster: 5k 0.5s, 10k 1.2s, 20k 4.0s, 40k 14.3s (ratio 3.3-3.6 per doubling) because each name is
  find-ed from offset 0 of the joined text; 50k names sharing " co" 20s. Adversarial repeats ("a","aa",..) are cubic (800 names 75s); not realistic.
## Judgement of the new rule
- "Half the length" IS a hand-set constant, not corpus-derived (the same 1/2 as the threshold). Sweep on identical data: token fraction 1/3 -> fused detection 0.76,
  2/5 0.84, 1/2 (shipped) 0.92, 3/5 0.98, 2/3 0.99, 3/4 1.00 with FP 0.000 throughout (containment carries coherence); i.e. detection is tuned by the literal and
  1/2 is not the optimum. Lead specified it, so not xfailed; disclose it against 2.4 or replace with a derived rule.
- Short names plus a shared legal word still mask: ["Shell","Shell Limited","Vodafone","Vodafone Limited"] unflagged because ANY holder with the token >= half of its name
  ("Shell Limited") ties ALL holders. Fused ["Bank of America..","Bank of China.."] and siblings stay unflagged when their dissimilarity is under the threshold
  (Tata Steel/Tata Motors IS flagged). All inside the ceilings the lead accepted. Coherent aliases (BofA, IBM, Meta/Facebook) are flagged: lexical ceiling.
