## Contract (minimal; reuse `_token_keys` / `_record_id`; edit only `tests/eval/score.py`, `resolve_entities.py` stays read-only)
`tests/eval/score.py::blocking_report(records, candidates, truth=None) -> dict`
- `records`: list of record dicts. `candidates`: iterable whose items start with `(id1, id2)` (engine 4-tuples ok); order, duplicates and
  self-pairs ignored. `truth`: `None` or iterable of id pairs (any order, duplicates ok).
- Block collection = token blocks (`_token_keys`) over distinct `_record_id`s, size >= 2, blocks with an identical member set counted once.
- Always present: `records` N, `total_comparisons` N(N-1)/2, `candidate_pairs` (distinct), `reduction_ratio` = 1 - candidate_pairs/total
  (ABSENT when total == 0), `block_assignments` = sum|b|, `cep_K` = sum|b|/2, `cnp_k` = sum|b|/N (dirty ER: |E1|+|E2| = N).
- Present only when `truth is not None`: `pair_completeness` = |truth & cand|/|truth| (absent if truth empty), `pairs_quality` =
  |truth & cand|/|cand| (absent if cand empty). Never 0, None, NaN or a stand-in when undefined; no recall/precision/F1 keys without truth.
- Hand-checked: N=5 `a{x,y} b{x,z} c{y,z} d{w} e{x}`, cand {ab, ac}: RR 0.8, sum|b| 7, K 3.5, k 1.4; truth {ab,cd,be}: PC 1/3, PQ 1/2.
- Per-stage counts are `stats` keys that already exist and are pinned (not new work): `candidate_pairs`, `blocks_used`, `blocks_purged`,
  `block_memberships_filtered`, `pairs_pruned_by_purging`, `pairs_pruned_by_meta_blocking`.
