## What changed
- `src/mcp_server/tools/plan_scope.py`: `_is_unique_combination`, `_minimal_unique_subset` (greedy drop, uniqueness is monotone),
  `classify_junction_and_weak_tables(graph, schemas, origins, sample_size, confidences)`. FK columns = child columns of P3's
  verified/probable/declared edges. Rows via one bounded `connector.extract(table, cols, batch_size=sample_size)` (same cap P3 samples
  with; `complete` flags whether the batch was the whole table). Junction = a minimal unique combination inside the FK columns with >=2
  columns (payload / surrogate irrelevant). Weak = FK-only set not unique, FK subset + one local column is a minimal key. Junction wins
  over weak; a key that is a single FK (1:1 extension, all-FK card) gets no role. No name tests (no id/ref/key literals; 6c passes).
  Output `{"junction": [...], "weak": [...]}`, entries `{table, origin, fk_columns, references ["col -> parent.col"], complete[, discriminator]}`.
  create_connector/_index_origins imported inside the function: new top-level imports shift the line that arch-lint-baseline.txt pins
  (plan_scope.py:58) and I may not edit the baseline.
- `analyze_dependencies.py`: calls the classifier right after the join graph exists; adds `table_roles` to the three graph-backed
  returns (ALGORITHMIC / LLM / FALLBACK). Tree, order, LLM path unchanged. `sample_size` hoisted to a local (same expression).
- `human_nodes.py::_build_deps_interrupt`: `data["table_roles"] = state.get("table_roles") or {}`. Built from STATE (section 2.6);
  `human_review_deps` body untouched (no feedback -> pauses with the payload; feedback -> echoes the tree).
- `map_fields.py`: Phase 1b after exact matching: a field whose name matches a family table's name (`_heuristic_match >= _HEURISTIC_ACCEPT`,

  dimension rows must exist first; `_write_child_rows` runs after the parent, so the find-or-create could not live there). When the
  primary table holds exactly one FK to the mapped table and that table has no FK back: one dimension row per DISTINCT mapped text
  (id = `deterministic_uuid("dimension_row", table, text-json)` -> idempotent, no lookup), blank/NULL text -> no row and link left

  dimension's own FK columns are dropped+reported (same reasoning as `_write_child_rows`), required unmapped FKs refuse the write. Only
  declared columns are written. `_write_child_rows` and `_apply_schema_changes` unchanged.
