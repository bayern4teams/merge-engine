## Judgement calls for the lead

- **J2 Hill numbers** over cluster size in records, singletons included. **J3** run-level variation = mean over multi-record clusters (only the one-cluster / none cases are pinned).
- **J4 flag rule is the implementer's.** Tests accept only what planted runs make unambiguous. A hard-coded cut is caught by the 2.4 grep and by the threshold-differs-between-corpora test, **not** by a scale pair: no behavioural scale pair is satisfiable by every literal-free rule (a noisy-names corpus rejects the oracle). A run with fewer than two multi-record clusters has no reference; flagging there is not asserted.

- Not asserted: whether a flagged cluster adds a `red_flags` entry or lowers the grade (flag, not a cut: the tests only require existing grading keys to survive).
